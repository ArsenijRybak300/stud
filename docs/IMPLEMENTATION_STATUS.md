# Состояние реализации

## Готово

- роли `admin` и `student`;
- учебные группы;
- привязка студентов к группе;
- семестры;
- повторяющийся недельный шаблон расписания для группы;
- четные, нечетные и все недели;
- копирование расписания в следующий семестр;
- отмена одного проведения занятия на конкретную дату;
- задания для всей группы;
- автоматическое создание персонального ответа для каждого студента;
- статусы: назначено, в работе, отправлено, выполнено;
- материалы задания;
- загрузка файла ответа;
- комментарии администратора;
- возврат ответа в работу без статуса `revision`;
- хранение файлов в Docker volume;
- строгий интерфейс для администратора и студента;
- backend-тесты.

## Следующая часть

- удаление отдельных загруженных файлов до отправки;
- история действий по заданию;
- уведомления о новых заданиях и отменах занятий;
- расширенные фильтры и поиск;
- резервное копирование файлов и базы данных.
