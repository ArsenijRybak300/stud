# Как самостоятельно разобраться в проекте

Проект лучше изучать не целиком, а последовательно. После каждого этапа нужно менять небольшой фрагмент кода и проверять результат.

## Этап 1. HTTP и REST

Изучить:

- что такое клиент и сервер;
- методы GET, POST, PATCH, DELETE;
- JSON;
- коды 200, 201, 204, 401, 404, 422.

Практика: открыть Swagger, зарегистрироваться и вручную создать занятие.

## Этап 2. FastAPI

Начать с:

- `backend/app/main.py`;
- `backend/app/api/router.py`;
- `backend/app/api/routes/health.py`;
- `backend/app/api/routes/lessons.py`.

Практика: добавить тестовый маршрут `/api/hello`.

## Этап 3. Pydantic

Открыть `backend/app/schemas/lesson.py`.

Понять:

- как JSON превращается в Python-объект;
- как работают типы и ограничения;
- почему неправильное время дает 422.

Практика: добавить обязательное поле или новое ограничение длины.

## Этап 4. База данных и SQLAlchemy

Открыть:

- `backend/app/models`;
- `backend/app/db/session.py`;
- `backend/alembic/versions`.

Понять:

- таблицу, строку и столбец;
- первичный и внешний ключ;
- связь один-ко-многим;
- сессию и транзакцию;
- назначение миграций.

Практика: добавить поле `color` в занятие через модель, схему и Alembic.

## Этап 5. JWT и безопасность

Открыть:

- `backend/app/core/security.py`;
- `backend/app/api/deps.py`;
- `backend/app/api/routes/auth.py`.

Проследить путь от пароля до токена и от токена до текущего пользователя.

Практика: уменьшить срок токена в тестовой среде и посмотреть поведение после истечения.

## Этап 6. Бизнес-логика

Открыть `backend/app/services/schedule.py`.

Практика: изменить глубину поиска ближайшего занятия с 14 до 21 дня и добавить тест.

## Этап 7. React

Начать с:

- `frontend/src/main.tsx`;
- `frontend/src/App.tsx`;
- `frontend/src/pages/SchedulePage.tsx`;
- `frontend/src/components/LessonDialog.tsx`.

Понять:

- компонент;
- состояние `useState`;
- эффект `useEffect`;
- свойства компонента;
- условный рендеринг.

Практика: изменить заголовок страницы и добавить отображение заметки занятия.

## Этап 8. Axios и связь frontend/backend

Открыть:

- `frontend/src/api/client.ts`;
- `frontend/src/api/lessons.ts`.

Проследить цепочку:

```text
нажатие кнопки → функция React → Axios → FastAPI → SQLAlchemy → PostgreSQL → JSON → React
```

## Этап 9. Docker

Открыть:

- `compose.yaml`;
- оба Dockerfile;
- `frontend/nginx.conf`.

Понять образ, контейнер, порт, volume, environment и healthcheck.

## Этап 10. Тесты

Открыть `backend/tests` и запускать:

```bash
pytest -v
```

Практика: написать тест, проверяющий, что пользователь не видит занятие другого пользователя.

## Рекомендуемый формат обучения

Для каждой темы:

1. Краткая теория.
2. Разбор конкретного файла StudentPlan.
3. Небольшое самостоятельное изменение.
4. Проверка через тесты, Swagger или интерфейс.
5. Объяснение результата своими словами.
